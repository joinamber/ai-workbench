# M1.2 Usability Validation

## Objective
Validate whether a designer can translate a common design intent into a usable AI-ready prompt in under 10 seconds without prompt-engineering coaching.

## Test mode
Open the UI with ?test=1.

The MVP records locally:
- intent-to-prompt time;
- compiler time;
- workflow selected;
- context present/absent;
- under-10-second pass/fail;
- Useful / Partially useful / Not useful;
- hesitation notes.

## Human acceptance gate
For common workflows, target >=90% of successful observed runs under 10 seconds. This is an experimental usability criterion, not a measured claim until real participants are tested.

## Recommended pilot
5-10 product designers. Use realistic tasks, do not coach workflow selection, and collect both quantitative timing and qualitative hesitation.

## Export
Use Export results in Test Mode to download m1.2-usability-results.json.
